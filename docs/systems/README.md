# Game systems

The game systems turn window events, player input, assets, and server updates into the parts of Dark Ages that a player can see and use. Each page follows one focused mechanism so the UI, game state, and network behavior remain easy to distinguish.

Start with the [event system](events.md), [UI and panes](ui.md), and [native UI controls](ui-controls.md) for the shared foundations. The remaining pages cover focused behavior such as [inventory drag actions](inventory-drag-actions.md), [movement](movement-and-swimming.md), [world interactions](world-interactions.md), [pathfinding and following](pathfinding-and-pursuit.md), the [fishing minigame](fishing.md), [bulletin boards and mail](bulletin-and-mail.md), dialogs, player interactions, character setup, settings, screenshots, portraits, formatted text, and the [local command dispatcher](local-command-dispatcher.md).
